# hangman-game
A simple Hangman style word guessing game made with python

🎮 How It Works

The computer randomly chooses a word from a list of words.

The player has 9 lives and can:

Guess individual letters
Guess the entire word
See which letters have been correctly guessed
Lose a life when an incorrect letter is entered
Win by revealing the entire word or guessing the word correctly

▶️ How to Run

Make sure Python is installed, then run:

python hangman.py

Follow the instructions in the terminal to play.
